# 风格与证据

## 来源与观察

2026-10-10 只读分析了两批用户提供的历史图例：85 个 VSDX 与 53 个现代文档包，共 138 页，未去重；2 个旧 VSD 未解析。原素材、业务原文及本机分析索引不随发布包分发。

显式属性不是最终渲染样式的完整统计：母版继承、主题、局部字符格式和分组嵌套都会影响视觉；不能按属性频次直接推断每张图的风格。

字体以 Microsoft YaHei 为主（2340 个显式 Font cell），SimSun 次之（380）。最常见显式字号为 8 pt（1545 个 Size cell），但源图的绘图尺寸与文档缩放会影响实际阅读；新图不机械照抄 8 pt。显式 Rounding=0 共 892 个，支持优先直角框。

视觉检查：2023 素材中的 Microsoft_Visio_Drawing.vsdx、Drawing1.vsdx、Drawing10.vsdx、Drawing11.vsdx 的首页经本机 Visio 导出并查看。可确认总体分层图、功能容器图、组件接口图的布局习惯；没有逐张视觉审核所有 138 页。

## 可复用规则

用户指定的形状选择原则优先于以下外观规则：优先使用所属具体图型的 Visio 模板/模具库母版，自绘可正常用于补充、定制与组合，无需额外确认。UML 按活动图、类图、时序图等具体类型选择，不能把外观相似视为语义等价。此原则是用户要求；脚本已实现基本流程母版自动映射与显式模具/母版投放，其他图型的自动映射及复杂母版适配未验证。

- 白底、黑字、黑灰细边线，中文字体优先微软雅黑；正式文档匹配需求时可选宋体。标题与模块标题加粗，标签居中。
- 大框表达系统边界或功能集合，小框表达组件或功能。优先直角矩形，避免装饰性圆角与阴影。
- 同层模块对齐，同类模块尺寸一致；先分配容器与标题空间，再排内部模块，避免文字紧贴边线。
- 以白色/灰色为基础；浅绿 #D7E3BF、浅蓝 #BDD7EE、浅橙 #F7CBAC、浅黄 #FEE599 作为有限的区分类色。示例采用浅色组合，属于基于素材的综合方案，不是精确复刻某一张图。
- 素材含实线主体边界与虚线外围边界；虚线的业务含义应在本次图中明确，不能从外观臆测“未实现”。
- 接口图使用有方向的箭头，并用接口名、状态或资源信息说明关系；控制流与数据流如果混用，给出图例。
- 用户补充规则：UML 与常规流程图连线优先接在框边中点；菱形判断框必须接在四个顶点。主流程的节点中心与连接线对齐，分支和回路用正交折线，端点真正胶合；有明确 UML 端口或记法要求时遵循对应要求。这是用户指定规范，不是原素材统计结论。
- 架构图优先横向展开，侧栏适合统一管理能力；密集图应拆页而非持续缩小文字。
- 避免复制原素材的项目名称、系统清单、厂商标识和真实部署信息到无关新图。

## 默认值的性质

生成器的 11 pt 正文、16 pt 图标题、0.75 pt 边线、0.25 英寸模块间距是针对新图可读性选择的默认值，不是素材统计结论。以最终插图尺寸调整。色彩不能作为唯一语义标识。
